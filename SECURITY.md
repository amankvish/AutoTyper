# Security Policy

## Supported Versions

Only the latest release of AutoTyper is supported with security updates.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0.0 | No        |

## Reporting a Vulnerability

AutoTyper is designed to be an **offline-first** application with no internet connectivity, database storage, accounts, or telemetry. It operates entirely on your local machine, eliminating remote exposure risks.

If you discover a security vulnerability or execution boundary bypass (e.g., elevation of privilege concerns or keyboard capturing anomalies), please report it to us by opening a GitHub issue or emailing the security team at **security@theiotlabs.com**.

We will investigate all reports and attempt to patch critical issues within 48 hours.
